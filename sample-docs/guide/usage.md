# Usage

## Running the linter

Point it at a folder: `mddocslint ./docs`. See [exit codes](#exit-codes) for scripting.

### Exit codes

| Code | Meaning |
| ---- | ------- |
| 0 | clean |
| 1 | problems found |
| 2 | usage error |
